# Petal Pixel

## Фронтенд

- При создании или переделке любого UI (экраны, компоненты, стили) используй скилл design-taste-frontend.
- После реализации UI прогоняй /impeccable critique и исправляй найденное, перед релизом — /impeccable audit.
- Источник правды по дизайну — DESIGN.md и PRODUCT.md; если их нет, сначала предложи запустить /impeccable init.
- Не подключай другие дизайн-скиллы (frontend-design и т.п.), чтобы правила не конфликтовали.
